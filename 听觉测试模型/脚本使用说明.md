# 模型调用脚本使用说明

本文档介绍如何使用封装好的检测脚本进行音频异常检测。

---

## 📁 脚本文件

| 文件名 | 用途 | 适用场景 |
|--------|------|---------|
| `detect_single.py` | 单文件检测 | 检测单个音频文件 |
| `detect_batch.py` | 批量检测 | 检测多个音频文件或整个文件夹 |
| `anomaly_detector.py` | Python模块 | 在其他Python代码中调用 |

---

### 3. 在Python代码中使用

```python
from anomaly_detector import AnomalyDetector

# 创建检测器
detector = AnomalyDetector('optimized_anomaly_model.pkl')

# 方式1: 简单判断是否异常
is_abnormal = detector.is_abnormal('audio.wav')
print(f"是否异常: {is_abnormal}")

# 方式2: 获取异常分数
score = detector.get_score('audio.wav')
print(f"异常分数: {score:.4f}")

# 方式3: 获取详细结果
result = detector.detect('audio.wav', return_details=True)
print(f"状态: {result['status']}")
print(f"等级: {result['level']}")
print(f"置信度: {result['confidence']:.2%}")

# 方式4: 批量检测
audio_files = ['audio1.wav', 'audio2.wav', 'audio3.wav']
results_df = detector.detect_batch(audio_files)
print(results_df)

# 获取模型信息
info = detector.get_model_info()
print(f"模型使用 {info['n_features']} 个特征")
```

## 🔧 命令行参数详解

### detect_single.py

```
用法: python3 detect_single.py <音频文件> [模型路径]

参数:
  音频文件       必需，待检测的音频文件路径
  模型路径       可选，默认为 optimized_anomaly_model.pkl

退出码:
  0 - 正常
  1 - 异常或错误
```

### detect_batch.py

```
用法: python3 detect_batch.py <输入路径> [选项]

位置参数:
  input              音频文件夹路径或文件路径

可选参数:
  -h, --help         显示帮助信息
  -m MODEL           模型文件路径 (默认: optimized_anomaly_model.pkl)
  -o OUTPUT          输出CSV文件路径
  -p PATTERN         文件匹配模式 (默认: *.wav)
  --recursive        递归搜索子文件夹

退出码:
  0 - 全部正常
  1 - 有异常或错误
```

## 💡 使用示例

### 示例1: 生产线实时监控

```python
from anomaly_detector import AnomalyDetector
import time
from pathlib import Path

# 初始化检测器
detector = AnomalyDetector('optimized_anomaly_model.pkl')

# 监控文件夹
watch_folder = Path('/data/audio/incoming')

while True:
    # 获取新文件
    new_files = list(watch_folder.glob('*.wav'))

    for audio_file in new_files:
        # 检测
        result = detector.detect(audio_file)

        # 异常处理
        if result['is_abnormal']:
            print(f"⚠️ 异常警报: {result['filename']}")
            print(f"   等级: {result['level']}")
            print(f"   分数: {result['anomaly_score']:.4f}")

            # 发送警报、记录日志等
            send_alert(result)

        # 移动已处理的文件
        audio_file.rename(f"/data/audio/processed/{audio_file.name}")

    time.sleep(60)  # 每分钟检查一次
```

### 示例3: Web API服务

```python
from flask import Flask, request, jsonify
from anomaly_detector import AnomalyDetector
import tempfile
import os

app = Flask(__name__)
detector = AnomalyDetector('optimized_anomaly_model.pkl')

@app.route('/detect', methods=['POST'])
def detect_audio():
    """音频检测API"""
    if 'audio' not in request.files:
        return jsonify({'error': 'No audio file'}), 400

    audio_file = request.files['audio']

    # 保存临时文件
    with tempfile.NamedTemporaryFile(delete=False, suffix='.wav') as tmp:
        audio_file.save(tmp.name)
        temp_path = tmp.name

    try:
        # 检测
        result = detector.detect(temp_path, return_details=True)
        return jsonify(result)
    finally:
        os.unlink(temp_path)

@app.route('/health', methods=['GET'])
def health():
    """健康检查"""
    info = detector.get_model_info()
    return jsonify({
        'status': 'healthy',
        'model_info': info
    })

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

使用API:
```bash
# 检测音频
curl -X POST -F "audio=@test.wav" http://localhost:5000/detect

# 健康检查
curl http://localhost:5000/health
```

## 🛠️ 高级配置

### 修改检测阈值

如果需要调整判定标准，可以修改 `anomaly_detector.py` 中的阈值:

```python
# 在 detect() 方法中
if anomaly_score < 0.1:      # 修改这里: 更严格用0.05, 更宽松用0.15
    level = 'CRITICAL'
elif anomaly_score < 0.2:    # 修改这里
    level = 'HIGH'
# ... 依此类推
```

### 并行处理加速

对于大量文件，可以使用多进程:

```python
from multiprocessing import Pool
from anomaly_detector import AnomalyDetector

def detect_file(audio_path):
    detector = AnomalyDetector('optimized_anomaly_model.pkl')
    return detector.detect(audio_path)

# 并行检测
audio_files = ['file1.wav', 'file2.wav', ...]
with Pool(processes=4) as pool:
    results = pool.map(detect_file, audio_files)
```

## ❓ 常见问题

### Q1: 如何安装依赖？

```bash
pip3 install --user numpy pandas scikit-learn librosa matplotlib seaborn scipy joblib PyWavelets tqdm
```

### Q2: 模型文件在哪里？

模型文件 `optimized_anomaly_model.pkl` 在训练后自动生成，确保在当前目录或指定路径。

### Q3: 支持哪些音频格式？

目前支持 `.wav` 格式。其他格式需要先转换:
```bash
ffmpeg -i input.mp3 -ar 44100 output.wav
```

### Q4: 检测速度慢怎么办？

1. 使用批量检测而不是单个检测
2. 使用多进程并行处理
3. 考虑使用更少的特征 (修改 `top_n` 参数重新训练)

### Q5: 如何提高准确率?

1. 收集更多训练样本
2. 调整 `contamination` 参数重新训练
3. 使用数据增强技术
