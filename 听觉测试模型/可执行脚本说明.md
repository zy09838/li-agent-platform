# 🎯 可执行脚本使用说明

## 双击运行的脚本文件

本文件夹包含5个可以直接双击运行的脚本（.command文件）：

### 🌟 主程序

**📱 检测系统.command** - 交互式主菜单
- 提供完整的功能菜单
- 单文件检测、批量检测、模型信息、帮助文档
- **推荐首次使用**

### ⚡ 快捷工具

**🎵 快速检测.command** - 单文件快速检测
- 双击打开，拖拽音频文件即可检测
- 最简单快速的使用方式

**📁 批量检测.command** - 文件夹批量检测
- 双击打开，拖拽文件夹即可批量检测
- 自动生成带时间戳的结果文件

**🔧 训练模型.command** - 重新训练模型
- 用于重新训练异常检测模型
- 可选先提取增强特征

**📖 查看帮助.command** - 查看使用文档
- 显示快速入门指南
- 列出所有可用文档

## 🚀 快速开始

### 首次使用

1. **双击** `检测系统.command`
2. 选择 **选项1** 进行单文件检测测试
3. 输入或拖拽一个音频文件路径
4. 查看检测结果

### 日常使用

**检测单个文件:**
- 双击 `快速检测.command`
- 拖拽音频文件
- 按回车查看结果

**批量检测:**
- 双击 `批量检测.command`
- 拖拽包含音频文件的文件夹
- 按回车开始检测
- 结果自动保存为CSV文件

## 💡 使用技巧

### 拖拽文件的方法

1. 双击打开.command脚本
2. 从Finder中拖动音频文件或文件夹
3. 松开鼠标，文件路径会自动填入
4. 按回车确认

### 查看检测结果

- 单文件检测: 结果直接显示在终端
- 批量检测: 结果保存为CSV文件，可用Excel打开
- 可视化图表: 训练时生成PNG图片

### 常见问题

**Q: 双击脚本没反应？**
A: 右键点击 -> 打开方式 -> 终端.app

**Q: 提示权限不足？**
A: 打开终端，运行: `chmod +x *.command`

**Q: 提示找不到模型？**
A: 先运行"训练模型.command"生成模型文件

**Q: 支持哪些音频格式？**
A: 目前支持.wav格式

## 🔧 高级用法

### 命令行直接调用

如果你熟悉命令行，也可以直接使用Python脚本：

```bash
# 单文件检测
python3 detect_single.py audio.wav

# 批量检测
python3 detect_batch.py /path/to/folder -o results.csv

# 查看帮助
python3 detect_single.py --help
```

### 在代码中调用

```python
from anomaly_detector import AnomalyDetector

detector = AnomalyDetector()
result = detector.detect('audio.wav')
print(result['status'])
```
