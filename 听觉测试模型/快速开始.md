# 快速开始 - 使用检测脚本

## 🎯 三种使用方式

### 方式1: 命令行单文件检测 (最简单)

```bash
python3 detect_single.py audio.wav
```

### 方式2: 命令行批量检测

```bash
python3 detect_batch.py /path/to/audio/folder
```

### 方式3: Python代码中调用

```python
from anomaly_detector import AnomalyDetector

detector = AnomalyDetector()
result = detector.detect('audio.wav')
print(result['status'])
```

### Python代码中使用

```python
from anomaly_detector import AnomalyDetector

# 初始化检测器
detector = AnomalyDetector('optimized_anomaly_model.pkl')

# 检测单个文件
result = detector.detect('audio.wav')
print(f"状态: {result['status']}")
print(f"分数: {result['anomaly_score']:.4f}")

# 批量检测
files = ['audio1.wav', 'audio2.wav', 'audio3.wav']
results_df = detector.detect_batch(files)
print(results_df)

# 简单判断
is_abnormal = detector.is_abnormal('audio.wav')
if is_abnormal:
    print("⚠️ 检测到异常!")
```
