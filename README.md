# 智能体协作平台 (Agentic Collaboration Platform)

> **版本**: v3.3  
> **状态**: 生产就绪 (Production Ready)

本平台采用**三大核心模块架构**，实现了从数据生产、模型训练到智能体应用的全链路闭环。

---

## 核心模块

| 模块 | 说明 |
|------|------|
| **智能体集群** | 5大业务智能体：视觉大师、听觉大师、计划灵枢、质量分析师、风险小灵通 |
| **模型训练中心** | 算法模型的全生命周期管理，支持 YOLO 和集成学习模型训练 |
| **数据集中心** | 数据标注、管理与版本控制，支持 COCO/YOLO/VOC 格式 |

---

## 快速启动

```bash
chmod +x start.sh
./start.sh
```

**服务端口**:
- 前端门户: `http://localhost:3000`
- 视觉推理: `:5000`
- 训练服务: `:5001`
- 数据服务: `:5002`
- 音频服务: `:5003`
- 认知中台: `:5004`
