## 项目简介

AI视觉质检分析工具是基于大模型API的智能图片质检系统，专注于汽车零部件的外观瑕疵检验。

### 核心功能

- ✅ **智能瑕疵检测** - 自动识别划痕、凹坑、颗粒等多种瑕疵
- ✅ **专业质检报告** - 生成结构化的质检分析报告
- ✅ **批量处理能力** - 支持批量分析多张图片
- ✅ **灵活输出管理** - 按时间自动归档分析结果
- ✅ **详细日志记录** - 完整记录分析过程

### 技术特点

- **基础模型:** Google gemini-3-pro-preview
- **API服务:** 工作流编排对话型应用
- **支持格式:** JPG, JPEG, PNG, GIF, WEBP
- **响应模式:** 阻塞模式 / 流式模式

## 命令行参数

| 参数 | 简写 | 说明 | 示例 | 必需 |
|------|------|------|------|------|
| `--single` | `-s` | 分析单张图片 | `--single img.jpg` | 否 |
| `--batch` | `-b` | 批量分析目录 | `--batch 测试数据/` | 否 |
| `--output` | `-o` | 指定输出根目录 | `--output 结果/` | 否 |
| `--mode` | `-m` | 响应模式 | `--mode streaming` | 否 |
| `--log` | `-l` | 保存日志到文件 | `--log run.log` | 否 |
| `--test` | `-t` | 测试API连接 | `--test` | 否 |

### 参数详细说明

#### --single / -s
分析单张图片，适用于快速测试或单个产品检测。

#### --batch / -b
批量分析指定目录下的所有支持格式的图片文件。

#### --output / -o
指定结果保存的根目录。默认保存在输入目录的上级目录。

#### --mode / -m
选择响应模式：
- `blocking`: 阻塞模式（默认），等待完整结果后返回
- `streaming`: 流式模式，实时显示分析内容

#### --log / -l
将详细的执行日志保存到指定文件，包含所有API调用记录。

#### --test / -t
测试API连接是否正常，不进行实际分析。

## 故障排除

### 常见问题

#### Q1: API连接失败

**现象:**
```
❌ API连接失败
```

**解决方法:**
1. 检查网络连接
2. 验证API密钥是否正确
3. 确认API服务是否正常

```bash
# 测试连接
python3 analyze.py --test
```

#### Q2: 文件上传失败

**现象:**
```
✗ 上传失败: HTTP 4xx
```

**可能原因及解决:**
- 图片格式不支持 → 使用JPG/PNG格式
- 图片文件过大 → 压缩至10MB以下
- 网络不稳定 → 重试或检查网络

#### Q3: 分析超时

**现象:**
```
❌ 分析失败: timeout
```

**解决方法:**
- 图片太大，建议压缩
- 网络延迟高，增加超时时间
- API服务繁忙，稍后重试

#### Q4: 没有生成结果文件

**检查:**
1. 是否有写入权限
2. 磁盘空间是否充足
3. 查看终端错误信息

#### Q5: 中文文件名乱码

**解决:**
使用英文或数字命名文件，避免特殊字符。

## API文档

### API端点

**基础URL:** `https://liai-app.chj.cloud/v1`

### 主要接口

#### 1. 测试连接
```
GET /parameters
```

#### 2. 上传文件
```
POST /files/upload
Content-Type: multipart/form-data

参数:
- file: 图片文件
- user: 用户标识
```

#### 3. 分析图片
```
POST /chat-messages
Content-Type: application/json

参数:
- query: 分析提示词
- inputs: {doc_name: {文件信息}}
- response_mode: blocking / streaming
- user: 用户标识
```

### 响应格式

#### 阻塞模式响应
```json
{
  "message_id": "xxx",
  "answer": "质检分析结果...",
  "metadata": {
    "usage": {
      "total_tokens": 3400,
      "prompt_tokens": 2400,
      "completion_tokens": 1000
    }
  }
}
```

#### 流式模式响应
```
data: {"event": "message", "answer": "分析内容..."}
data: {"event": "message_end", "metadata": {...}}
```
