## 🚀 方案一：使用API批量测试（推荐）

### 步骤1：部署优化后的工作流到Dify

1. **登录Dify平台**
   ```
   访问: https://liai-app.chj.cloud
   ```

2. **导入工作流配置**
   - 进入"工作室" → "应用" → "创建应用"
   - 选择"工作流编排"
   - 点击右上角"导入DSL"
   - 上传文件: `product-detect-agent-optimized.yml`
   - 确认导入

3. **检查工作流节点**
   - 验证11个节点是否正常加载
   - 检查节点连接关系
   - 确认变量引用无误

4. **测试单张图片**
   - 点击"运行" → 上传一张测试图片
   - 观察每个节点的输出
   - 确认工作流正常运行

5. **发布应用**
   - 点击右上角"发布"
   - 选择"API访问"
   - 记录API Key和应用ID

### 步骤2：配置批量测试脚本

创建适配新工作流的测试脚本：

```bash
cd /Users/zhuyanbin/Desktop/大模型调用测试
cp analyze.py analyze_optimized.py
```

然后编辑 `analyze_optimized.py`，修改API配置：

```python
# 在文件顶部修改配置
BASE_URL = "https://liai-app.chj.cloud/v1"
API_KEY = "你的新工作流API_KEY"  # 从Dify获取
```

### 步骤3：运行完整测试

```bash
cd /Users/zhuyanbin/Desktop/大模型调用测试

# 批量分析完整测试数据集
python3 analyze_optimized.py --batch "完整测试数据/images" --output "完整测试数据" --log "optimized_full_test.log"
```

**预计耗时**: 约10-15分钟（21张图片 × 30秒/张）

### 步骤4：计算准召率

等待批量分析完成后：

```bash
# 计算准召率
python3 calculate_precision_recall.py
```

脚本会自动：
1. 加载原始标注数据（29个annotations）
2. 加载最新的大模型检测结果
3. 匹配文件名
4. 计算准确率、召回率、F1分数
5. 生成详细报告

### 步骤5：查看结果

```bash
# 查看准召率报告
cat "完整测试数据/分析结果_[时间戳]/precision_recall_report.md"

# 或者在VS Code中打开
code "完整测试数据/分析结果_[时间戳]/"
```

## 🔍 测试注意事项

### 1. API配置问题

如果遇到API调用失败：

```bash
# 测试API连接
python3 analyze.py --test

# 如果失败，检查：
# - API_KEY是否正确
# - BASE_URL是否正确
# - 网络连接是否正常
```

### 2. 图片格式问题

某些图片可能不被支持：

```bash
# 检查图片格式
file 完整测试数据/images/*.jpg

# 转换格式（如果需要）
for img in 完整测试数据/images/*.{png,gif,webp}; do
  convert "$img" "${img%.*}.jpg"
done
```

### 3. 文件名匹配问题

确保检测结果和标注能正确匹配：

```bash
# 检查文件名对应关系
python3 << EOF
import os
import json

# 列出images
images = sorted(os.listdir('完整测试数据/images'))
# 列出annotations
annotations = sorted(os.listdir('完整测试数据/annotations'))

print("图片文件:")
for img in images[:5]:
    print(f"  {img}")

print("\n标注文件:")
for ann in annotations[:5]:
    print(f"  {ann}")
EOF
```

### 4. 结果解析问题

如果准召率脚本报错：

```bash
# 检查JSON格式
python3 -m json.tool "完整测试数据/分析结果_*/原始数据.json" > /dev/null

# 如果有错误，手动检查文件
code "完整测试数据/分析结果_*/原始数据.json"
```
